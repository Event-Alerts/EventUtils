# EventUtils
A mod that alerts you when a Minecraft event happens (among many other things to help you in events!)

EventUtils is THE mod to use when playing Minecraft events, whether casual or hardcore competitive ⚔️

Possible thanks to the Discord server [Event Alerts](https://eventalerts.gg/discord?utm_source=github&utm_medium=listing&utm_campaign=eventutils)!

## Features
- In-game notifications for events:
    - Skeppy events
    - Famous events (Karl, MrBeast, etc...)
    - Money events ($5+ USD)
    - Hypixel events
    - Civilization events
    - And more!
- Auto-teleport to events
- Hide players and entities with a keybind (specify custom groups for specific players/entities/settings)
- Confirm disconnect and confirm window close
- DiscordRPC (shows which event you're currently in!)
- Bee icons in player list for Event Alerts members and other players using the mod
- Simplified queue message for InvadedLands.net
